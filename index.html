Structural Dynamics Characterization
UT Austin Capstone
Jan – May 2024
Applied Materials tests robotic arms on external test stands before deploying them in production semiconductor machines — but for results to be accurate, the test stand must replicate the vibrational characteristics of the real machine. This project developed a process to extract damping ratios and spring constants from free-response accelerometer data, enabling test stand designs to be tuned to match any target structure. We applied the methodology to a lab table and a 3D printer carriage as test objects — instrumented with PCB Piezotronics accelerometers, acquired with a Zoom F8 DAQ, and modeled in MATLAB. The result is a replicable characterization workflow that generalizes to any structure.
