Structural Dynamics Characterization UT Austin Capstone Jan – May 2024
Applied Materials tests robotic arms on external test stands before deploying them inside production semiconductor machines. For those test results to be accurate, the test stand must replicate the vibrational characteristics of the real machine. This project developed a process to do exactly that: extract damping ratios and spring constants from free-response accelerometer data so a compliant test stand can be designed to match any target structure. We applied the methodology to a lab table and a 3D printer carriage as test objects, instrumented with PCB Piezotronics accelerometers, acquired data via a Zoom F8 DAQ, and modeled the structural dynamics in MATLAB.

NASTRAN HDF5 Extract
Desktop GUI tool for processing MSC Nastran HDF5 output files. Instead of examining results one subcase at a time in a post-processor, this tool lets engineers target specific elements or nodes, sweep across all subcases at once, and identify the governing load cases. Calculates Von Mises, max/min principal stresses for solids and shells, and exports to CSV. This is the tool behind the 800% workflow acceleration on my resume.
Python Tkinter GUI h5py + NumPy + Pandas Used in production at Nordam
