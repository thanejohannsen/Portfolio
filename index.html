Structural Dynamics Characterization
UT Austin Capstone
Jan – May 2024
Applied Materials tests robotic arms on external test stands before deploying them inside production semiconductor machines. For those test results to be accurate, the test stand must replicate the vibrational characteristics of the real machine. This project developed a process to extract damping ratios and spring constants from free-response accelerometer data so a compliant test stand can be designed to match any target structure. We applied the methodology to a lab table and a 3D printer carriage, instrumented with PCB Piezotronics accelerometers, acquired data via a Zoom F8 DAQ, and modeled structural dynamics in MATLAB.
